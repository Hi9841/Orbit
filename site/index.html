Window placement

Place the focused window by moving toward an edge.

Hold Ctrl and Alt. Move the pointer toward a side or corner, then release. Orbit draws a radial menu and a placement preview. Releasing commits the move on the monitor work area. Press Escape before you release to cancel. Press Ctrl+Alt+Z to undo.

Scripts

orbit left-half
orbit --list-actions
orbit --status
orbit --export-settings preferences.json
orbit --import-settings preferences.json

Use the full path to orbit.exe when it is not on PATH. --export-settings requires a new file path. Import checks the whole file before it applies the file. Exit code 0 means success. Exit code 1 means the operation failed. Exit code 2 means the arguments are invalid.

Use

Launch Orbit from the Start menu. Focus the window you want to arrange. Hold the trigger. The default trigger is Ctrl+Alt, with no extra key. Right-click the notification-area icon to open settings or quit.

Settings has eight pages. They are General, Radial, Preview, Shortcuts, Frames, Exclusions, Advanced, and About. A custom frame is a fraction of the monitor work area. Each edge runs from 0 to 1.

  • Change the trigger in Settings, including an optional extra key.
  • Open settings with orbit --settings or orbit://settings.
  • Apply a window action with orbit://action/left-half. URI commands are limited to window actions and opening settings.
  • Run orbit --list-actions before scripting a name.

One resident

One Win32 message loop owns the notification icon, the global shortcuts, the overlay windows, the action history, the stash, and the settings window. Placement uses the monitor work area. Orbit stores history on the live window. A recycled handle does not inherit another window's positions.

The settings window uses native controls. The radial menu is drawn into a layered window. Update checks run on background threads and return to the message loop. Orbit does not ship a WebView. It does not ship a separate UI runtime.

  • Read the architecture for the process boundary and the UI choice.
  • Preview opacity defaults to 170. That value is the layered-window alpha, from 0 to 255.
  • Window-resize animation is off by default. The duration setting is 180 ms.
  • Fullscreen windows are ignored by default.

Install and updates

The installer writes to your Programs directory. It registers notification-area launch, optional logon launch, the orbit:// handler, and Windows uninstall metadata. It does not add a service. It does not request elevation.

Update manifests are signed with Ed25519. Orbit requires HTTPS. It bounds the read, rejects altered metadata, and checks the installer SHA-256. It checks the staged file again before launch. A prompt comes before the download. The executable and the installer are unsigned. Windows can show a publisher warning.

  • Download a release and the matching source archive.
  • Uninstall from Windows Settings, Apps. Preferences stay unless you delete them.
  • Silent uninstall keeps preferences. /REMOVESETTINGS=1 removes them.
  • Read the release guide for the update manifest.

Limits

Numbered virtual-desktop moves are not included. Next and previous virtual-desktop switching are not included. Windows does not document an equivalent. Stage Manager, Dock integration, haptics, and iCloud sync stay on macOS.

The Fullscreen action fills the monitor. It does not enter another application's fullscreen mode. Orbit is GPL-3.0-only. It is a separate project from Loop. It does not claim exact visual or behavioral parity with Loop.

  • Read the parity checklist for adaptations and excluded behavior.
  • Read the verification notes before you treat a hosted run as acceptance on your own PC.
  • Windows 10 and 11 mixed-DPI behavior still needs acceptance testing.
  • Screen-reader behavior still needs acceptance testing.
